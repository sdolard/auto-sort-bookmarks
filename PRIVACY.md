# Privacy Policy for AI Bookmark Organizer

**Last updated:** September 2026

"AI Bookmark Organizer" (the "Extension") is a browser extension designed to help you organize your bookmarks using AI. We believe your data belongs to you.

## 1. Data Collection and Usage
- **Bookmarks & History:** The Extension requests access to your browser's bookmarks and history to analyze and sort your links. **This data never leaves your computer**, except for the specific bookmarks you choose to send to the AI for categorization.
- **AI Processing:** To categorize your bookmarks, the Extension sends the titles and URLs of your bookmarks directly to the DeepSeek API. This is done exclusively using the personal API Key that you provide in the Extension's settings.
- **No Analytics or Tracking:** The developer of this Extension does not collect, store, or transmit any of your personal data, bookmarks, browsing history, or API keys to any third-party servers (other than the DeepSeek API you explicitly configure).

## 2. API Key Storage
Your DeepSeek API Key is stored locally on your device using Chrome's local storage. It is never synced to the cloud or accessible to the developer.

## 3. Third-Party Services
The Extension relies on the DeepSeek API. By using the Extension, the data sent for classification (Bookmark URLs and Titles) is subject to DeepSeek's own privacy policy and terms of service.

## 4. Contact
If you have any questions about this privacy policy, please open an issue on the project's GitHub repository.
